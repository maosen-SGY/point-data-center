接口接入说明（本地版）

所有接口采用 HTTP POST + JSON，通过请求头 secret-key 鉴权。公共参数： region / language / currency / date_range。

对接流程

  1. 前往 个人中心 管理密钥与调用明细。
  2. 前往 定价页 查看积分规则：榜单接口单次扣减 = 0.1 × (page/5)，详情接口单次扣减 = 0.1。
  3. 按下方入参/出参结构完成接口接入。

示例接口

Path：/openapi/v1/tiktok/creator/rank

POST 
{
  "region": "US",
  "language": "zh-CN",
  "currency": "USD",
  "date_range": "2026-06-01~2026-06-07",
  "page": 10,
  "page_size": 20
}

榜单接口积分示例：0.1 × (10/5) = 0.2 积分/次
